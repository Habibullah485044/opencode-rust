These skills were written for Claude Code. Habi maps their tool names in
its system prompt: Skill tool = read that SKILL.md, TodoWrite = todo,
Task/subagent = spawn, Bash/Read/Write/Edit/Grep/Glob = Habi's tools.
Habi's spec step picks the 1-3 skills that fit each task.
